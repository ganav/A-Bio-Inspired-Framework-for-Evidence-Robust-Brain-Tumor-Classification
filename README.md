Dataset Description
The dataset contains 7,200 human brain MRI images categorized into four classes:

Glioma
Meningioma
Pituitary tumor
No tumor

https://www.kaggle.com/datasets/masoudnickparvar/brain-tumor-mri-dataset?resource=download
